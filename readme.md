# Global Stocks Trading Dashboard

A responsive, real-time trading dashboard for tracking popular global stocks — built with **HTML, CSS, and JavaScript** using live market data from the [Finnhub API](https://finnhub.io/).

---

## Overview
The **Global Stocks Trading Dashboard** provides a modern interface for monitoring stock performance in real time.

**Key capabilities:**
- View live prices and percentage changes.
- Search stocks by symbol or company name.
- Add or remove stocks from a personalized watchlist.
- Display top gainers and losers updated dynamically.
- Auto-refresh every 30 seconds for the latest market data.

---

## Features
- Live Market Data — Prices and percentage changes from the **Finnhub API**.
- Interactive Watchlist — Easily add or remove stocks.
- Instant Search — Filter results quickly.
- Market Highlights — Top Gainer & Top Loser summary cards.
- Automatic Updates — Data refresh every 30 seconds.
- Clean UI — Optimized for laptop/desktop screens *(mobile support in progress)*.

---

## Technology Stack
| Layer       | Technology |
|-------------|------------|
| **Frontend** | HTML, CSS, JavaScript (ES6 Modules) |
| **API**      | Finnhub Stock Data API |
| **Backend**  | None — fully client-side application |

## Setup & Usage
1. **Clone or download** this repository:
   ```bash
   git clone https://github.com/<your-github-username>/<repo-name>.git
   cd <repo-name>
   ```
2. **Open the application**  
   Launch `index.html` in a modern browser *(supports ES6 modules)*.
3. **Explore features**  
   - Use the search bar to find stocks.  
   - Add or remove stocks from your watchlist.  
   - Watch live updates happen automatically.
